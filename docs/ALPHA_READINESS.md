# Alpha Readiness

OpenBackend is ready for private self-hosted alpha testing.

## Ready Now

- One-button Docker deploy with `npm run deploy`.
- Local, NAS, and VPS compose profiles.
- SQLite document collections.
- WebSocket collection watches.
- Self-hosted auth bootstrap, sessions, roles, and API keys.
- Protected admin routes and protected write APIs by default.
- Optional authenticated realtime sockets.
- Basic IP rate limiting.
- Local function timeout controls and worker-isolated function registration.
- Filesystem storage with persistent metadata, download, and delete.
- Runtime PostgreSQL document adapter.
- Runtime MinIO/S3-compatible object storage adapter.
- Local functions with protected run calls.
- Dashboard login/bootstrap, collection create, API-key creation, import, export, and file delete.
- Website, POS/kiosk, and IoT starter examples.
- Backup and restore scripts.
- PostgreSQL and MinIO backup/restore support.
- Server smoke tests.
- Docker profile smoke test commands for local, NAS, and VPS.
- Real-domain TLS validation script and checklist.

## Use For

- Website builds.
- Client demos.
- Local apps.
- Kiosks and POS tools.
- Internal tools.
- LAN/NAS deployments.

## Not Yet Public-Production Ready

- Field-level permission rules.
- Stronger function sandbox policies and resource quotas.
- Deeper PostgreSQL/MinIO operational testing under load.
- Dedicated brute-force login protection.
- Full restore verification test with live data.

## Current Position

Private alpha deploy-ready: yes.

Public internet production-ready: not yet.
